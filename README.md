# Frequent Photos developer website

Public static developer information for Frequent Photos / 자주보는 사진.

Only these website files belong in this public repository. The mobile app's
source code, signing materials, user photos, and build artifacts must not be
published here.

- `index.html`: developer information and the existing Android privacy-policy link
- `app-ads.txt`: authorized AdMob seller declaration, served at the website root
- `.nojekyll`: publish static files without Jekyll processing

This website does not replace the iOS privacy policy. Linking this website in a
store listing and AdMob's subsequent crawl/verification are separate steps.
